# Merchandising Checklist — Pre-Publish

Complete every item before a product can move from draft to live.

## 1. Product Identity
- [ ] SKU follows `BRAND-CAT-###` convention and is unique
- [ ] Product name matches brand style guide (Title Case, no emojis)
- [ ] Brand assigned
- [ ] Primary category assigned; secondary tags (Season, Occasion) applied
- [ ] Slug is URL-safe, lowercase, hyphenated

## 2. Content
- [ ] Short description (1–2 sentences, ≤ 160 chars)
- [ ] Long description with fabric, work, included pieces, styling note
- [ ] Fabric field populated from fabric-glossary.md
- [ ] Included pieces listed (Shirt / Trouser / Dupatta / etc.)
- [ ] Care instructions present

## 3. Imagery
- [ ] Hero image 2000 × 2500 px, pure white background
- [ ] Minimum 4 gallery images (front, back, close-up, styled)
- [ ] All images match white balance and crop ratio
- [ ] Alt text populated for every image using image-alt-library.md template
- [ ] No watermarks, price stickers, or logos baked in
- [ ] Total image weight optimised (< 400 KB hero, < 80 KB thumb)

## 4. Pricing & Inventory
- [ ] Price in PKR, integer, no decimals
- [ ] Compare-at price populated if on sale, and > selling price
- [ ] Stock quantity accurate against warehouse count
- [ ] Reserved / draft quantity reconciled
- [ ] Tax class assigned

## 5. Attributes & Size
- [ ] Size variants created (XS–XXL for pret; N/A for unstitched)
- [ ] Colour attribute populated with standardised colour name
- [ ] Size chart linked from size-guide.md
- [ ] Weight and dimensions filled for shipping

## 6. SEO
- [ ] Meta title formatted `<Product> — <Brand> | Elite Brands`
- [ ] Meta description ≤ 160 chars, includes primary keyword
- [ ] OG image set (hero)
- [ ] JSON-LD Product schema validates
- [ ] Canonical URL set

## 7. Merchandising Signals
- [ ] Correct badges applied (max 2 per PDP)
- [ ] Related products curated (min 4)
- [ ] Collection membership confirmed
- [ ] Homepage / campaign placement flagged if applicable

## 8. Final QA
- [ ] Preview on desktop and mobile
- [ ] All CTAs functional (add to cart, wishlist, size chart)
- [ ] Reviewer sign-off recorded
- [ ] Publish date scheduled or set to now
