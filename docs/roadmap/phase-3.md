# Phase 3 Roadmap

## Overview

Longer-horizon candidate initiatives beyond Phase 2, contingent on business priorities and Phase 2 outcomes.

> These are planning placeholders, not commitments. Actual prioritization should match the project's roadmap as defined by the team/product owner.

## Candidate Initiatives

### Internationalization

- Multi-currency pricing and display.
- Localized content (product descriptions, UI copy) if the brand expands to new markets.

### Advanced Analytics

- Deeper admin analytics (cohort analysis, brand/category performance trends) beyond the summary metrics described in `../admin-guide/analytics.md`.

### Customer Loyalty / Promotions

- Discount codes, loyalty points, or promotional pricing rules affecting the Catalog and Orders APIs (`../api/catalog.md`, `../api/orders.md`).

### Third-Party Integrations

- Potential integration with external inventory/ERP systems if the catalog scales beyond manual admin management.
- Marketing/email platform integration for order confirmations and campaigns.

## Dependencies

Most Phase 3 items depend on the stability and completion of Phase 2 work (`phase-2.md`) and on addressing outstanding technical debt (`technical-debt.md`).
