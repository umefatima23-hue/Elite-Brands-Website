# Future Features (Unscheduled)

## Overview

A backlog of feature ideas not yet assigned to a specific phase. This list is exploratory and should be triaged into `phase-2.md`/`phase-3.md` or discarded as priorities become clearer.

> None of these are commitments. Actual scope should match the project's roadmap as defined by the team/product owner.

## Storefront Ideas

- Product reviews and ratings
- Related/recommended products on product detail pages
- Wishlist / save-for-later
- Guest checkout (if not already supported)

## Admin Ideas

- Bulk import/export of products (CSV) — see `../admin-guide/products.md`
- Role granularity beyond a single "admin" role (e.g., catalog editor vs. order manager)
- Audit log of admin actions (who changed what, when)

## Platform Ideas

- Automated end-to-end test suite covering the flows in `../testing/`
- CI-integrated performance budget checks (see `../testing/performance-testing.md`)
