# Folder Structure

## Overview

This document describes the conventional folder structure expected for a project using this stack (React, Vite, TanStack Router, TypeScript, TailwindCSS, shadcn/ui, Supabase). It is a reference guide, not a confirmed map of this repository's actual contents.

> This should match the project's implementation. This document was produced without direct repository access; verify actual folder names and contents directly in the repository.

## Expected Top-Level Layout

```
Elite-Brands-Website/
├── src/                  # Application source (not modified/read to produce this doc)
│   ├── app/ or routes/   # TanStack Router route definitions
│   ├── components/       # Reusable UI components (incl. shadcn/ui-based components)
│   ├── stores/           # Client-side state management
│   ├── hooks/            # Custom React hooks
│   ├── lib/              # Utilities, Supabase client setup, helpers (name unconfirmed)
│   └── types/            # Shared TypeScript types (name unconfirmed)
├── public/               # Static assets served as-is
├── supabase/              # Supabase config/migrations (if using the Supabase CLI)
├── docs/                 # Project documentation (this folder)
├── package.json
├── bun.lock
├── vite.config.*
├── tsconfig*.json
├── tailwind.config.*
└── routeTree.gen.ts      # TanStack Router generated route tree
```

## Notes on Generated Files

- `routeTree.gen.ts` is expected to be auto-generated by the TanStack Router plugin based on the route definitions in `src/routes/` (or equivalent). It should not be hand-edited — see `TanStack-Router.md`.

## Notes on `docs/`

This `docs/` folder is documentation-only and does not affect the application build. It is organized as:

- `docs/api/` — backend/API-facing documentation
- `docs/testing/`, `docs/qa/` — test planning and QA references
- `docs/operations/` — deployment/ops runbooks
- `docs/roadmap/` — forward-looking planning notes
- `docs/admin-guide/` — end-user guide for admin operators
- `docs/developer/` — this folder; engineering-facing reference material
