# WhatsApp Templates — Elite Brands

Customer-facing. Keep short, warm, and specific. Use variables in `{{curly_braces}}`.

## 1. Order Received

```
Assalam-o-Alaikum {{customer_name}} 👋

We've received your order #{{order_id}} at Elite Brands.
Our team is reviewing it now and you'll get a confirmation shortly.

Order total: Rs {{order_total}}
Track anytime: {{order_link}}

Shukriya for shopping with us.
— Elite Brands
```

## 2. Order Confirmed

```

{{item_count}} item(s) · Rs {{order_total}}
Delivery to: {{city}}
Expected dispatch: {{dispatch_date}}

```
