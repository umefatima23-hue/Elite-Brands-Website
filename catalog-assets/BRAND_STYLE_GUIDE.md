# Brand & Copy Style Guide

Applies to every product, category, brand and marketing surface on Elite Brands.

## Store name

- Always written as **Elite Brands** (two words, Title Case).
- Never `elitebrands`, `ELITE BRANDS`, or `Elite-Brands` in copy.
- Domain and slugs use lowercase (`elitebrands.pk`).

## Brand names

Write brand names exactly as the label writes them.

| Correct         | Wrong                                    |
| --------------- | ---------------------------------------- |
| Sana Safinaz    | SanaSafinaz, sana safinaz, SANA SAFINAZ  |
| Maria B         | Maria.B, MariaB, maria b                 |
| Gul Ahmed       | GulAhmed, GUL AHMED                      |
| Khaadi          | KHAADI, khaadi                           |
| Sapphire        | SAPPHIRE, Saphire                        |
| Zara Shahjahan  | Zara ShahJahan, zara shahjahan           |
| Elan            | ELAN, Élan                               |
| Asim Jofa       | AsimJofa, ASIM JOFA                      |
| Nishat Linen    | NishatLinen, NISHAT                      |
| Cross Stitch    | CrossStitch, Cross-Stitch                |

Slugs are always lowercase, hyphenated ASCII (`sana-safinaz`, `maria-b`).

## Capitalization

- **Product names:** Title Case. Capitalize nouns, verbs, adjectives; lowercase articles and short prepositions (`of`, `in`, `and`, `the`).
  - ✅ `Rosewood Embroidered Lawn`
  - ❌ `Rosewood embroidered lawn`, `ROSEWOOD EMBROIDERED LAWN`
- **Category names:** Title Case (`Luxury Lawn`, `New Arrivals`).
- **Colors:** Title Case (`Dusty Rose`, `Ivory`, `Midnight Blue`).
- **Fabrics:** Title Case (`Cotton Net`, `Chiffon`, `Karandi`).
- **Body copy / descriptions:** Sentence case. One space after periods.

## Currency and numbers

- Currency is **PKR**. Display as `Rs 12,500` on the storefront; store as integer `12500` in the CSV.
- No decimals — Pakistani retail pricing is whole rupees.
- Use commas as thousands separators in display only, never in the CSV.

## Punctuation

- Em dash `—` in meta titles and headlines.
- Hyphen `-` only inside slugs and compound modifiers (`ready-to-wear`).
- Straight quotes `"` in CSV cells. Curly quotes are fine in prose.

## Voice

- Confident, understated, editorial.
- Describe the garment: fabric, cut, embellishment, styling.
- Avoid marketing hype: `stunning`, `must-have`, `exclusive`, `!!!`.
- Never invent claims (thread count, origin, hand-stitch hours) that merchandising hasn't confirmed.

## Reserved terms

Only use when accurate and verified:

- `Handcrafted`, `Hand-embroidered`, `Chikankari`, `Zardozi`, `Pure Silk`, `Organza`.
